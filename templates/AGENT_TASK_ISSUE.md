## Receiving-agent procedure

2. Read this complete issue and relevant comments.
3. Verify current project instructions, default branch/commit, dependencies, task status, and authorization.
4. Claim by commenting with task ID, stable agent identity, role, UTC timestamp, and intended branch; re-fetch comments to detect conflicts.
5. Create a separate implementation branch from latest default.
6. Execute only the approved scope.
7. Post progress, blockers, decisions, PR, exact tests/results, limitations, and next action here.
8. Submit for independent review; do not self-accept.
